# CSS Parallax Project

This project demonstrates a parallax scrolling effect using pure **HTML & CSS**.  
It features layered background images, responsive layout, and simple hover effects.

## 🌐 Live Demo
[View Project](https://naranishivaprasad.github.io/css-project/example.html)

## 📂 Project Structure
- `example.html` → Main HTML file  
- `example.css` → Styling file  
- Images used for background and content  

## ⚡ Features
- Parallax scrolling with CSS `background-attachment`  
- Responsive design with media queries  
- Clean and minimal UI
